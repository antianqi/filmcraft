# 画面与连续性

## 让产品含义驱动设计

以“请求 → 工作 → 变化 → 可用结果”或同样具体的因果链组织产品片。真实素材提供可验证的状态，原创构图与动画解释重点。允许原创展示组件和品牌段；复刻现有界面时优先真实采集，避免把自己画的功能当作产品已有能力。

不以素材数量或抽象元素数量衡量设计。可拆出输入框、文件、Diff、结果卡、文档或设备，让它们成为镜头里的对象；每次变形、展开或移动都应解释一个关系。没有信息作用的圆环、管线、HUD、小字和持续脉冲删去或弱化。

插件图标采用黑白橙；影片仍服从目标产品的视觉语言。红绿用于真实状态语义，装饰色有明确来源。需要明显改变既定视觉方向时按当前创作模式记录或确认，不悄悄改成另一种片种。

## 镜头检查

| 现象 | 修正方向 | 验证对象 |
| --- | --- | --- |
| 录屏换录屏，只有过场 | 找每镜核心对象，拆出重点并通过动作解释变化，再回到可识别页面 | 对比每镜新信息和动作终点 |
| 抽象动画很多，产品消失 | 把形体换成真实工作对象，让结果与前面的请求对应 | 产品与功能证据在正常速度下可辨认 |
| 每帧都挤满字幕、线条和面板 | 一镜一个主动作、一个阅读层，其余降亮度/退出；空间分层通常先用三个主要层 | 全尺寸和 480px 宽预览的视线焦点 |
| 标题＋截图重复，读起来像 PPT | 延续同一个对象、状态和相机；给剩余时间一个真实操作或新的信息，不用无意义漂移填时长 | 连续片段和相邻切点前后帧 |
| 内容落定后静止过久 | 说明这段停留的阅读任务；空白信息画面静止约三秒以上需重点审查，品牌和长内容可合理更长 | 静止段是否仍在提供必要信息 |
| 控件小，但大字幕说“点击这里” | 点击前做带上下文的近景，指针命中真实位置，再退回结果 | 真正的按钮和选中状态能读清 |
| 主体在切镜时跳位置/缩放 | 记录上一镜终态与下一镜初态；接续同一输入框、文件、Diff 或标志。硬切有意图即可，不强制所有镜头形变 | 切点前一帧/后一帧，避免意外空帧 |
| 手机边框穿过黑色字幕 | 让字幕落在稳定区域或加不透明浅色底，逐帧检查边框与文字交叉 | 编码后近景、字幕出现/退出阶段 |

## 阅读与空间

1080p 的主要字幕以有效字高约 56px 以上、副文案/CTA 约 32px 以上为检查起点；按最终像素与缩小播放效果判断，不以源码 fontSize 代替。不是每个 UI 小字都要放大：说明哪些是支持纹理，哪些必须阅读。必要的原生操作、代码差异和结果状态应单独获得读图时间。

图片保留原比例，宽屏与竖屏转换用有目的的裁切与遮挡。优先原始高清资源和 2–4 倍截图；透视推进时检查栅格化链路，DOM 放大可用布局级 zoom，避免低分辨率合成层被再次放大。密集信息回到正视，侧向视角用于物体的完整动作弧。

加速度、非均匀错峰和接触影塑造节奏；画面落定后保留阅读与呼吸。品牌完整字标至少留一秒，批量元素落位至少留半秒。节拍约束动作时机，默认不驱动全画面持续抖动或缩放泵。
