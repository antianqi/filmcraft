# 音频制作

1. 明确本次声音范围：配乐、音效、配音、静音、候选清单或最终混音。保留用户指定音源和已有画面；候选任务只交候选，不擅自混入成片。用户要求生成音乐时核对实际可用的生成工具、预算和授权；现成曲目、模型作曲、录音与脚本混音分别标注。
2. 按 [依赖与引擎](../filmcraft-video/references/dependencies.md) 定位 Video Shotcraft，读取 `sound-design.md` 与 `sfx-sourcing.md`；有强节奏配乐时继续读 `music-beat-sync.md`。从当前片种和动作选择音色，不只按搜索关键词选第一个结果。
3. 锁定画面版本，建立“动作锚点 → 音源 → 裁剪窗口 → 增益 → 内部峰值 → 输出偏移”的事件表。先选音乐再重排切点，或在画面基本确定后选曲；用户已定音乐时先分析拍点。时长/动作改动后全表重对。
4. 按需使用 Shotcraft 的 Freesound 选材脚本。保存实际下载文件的素材页、作者、确切许可、原文件或预览标记、哈希和测量。失败请求做有界重试，只重试失败对象；换候选时重新核实，不默默降级到无来源旧音包。源文件与处理后混音分别记录，保留必要署名。
5. 读 [同步与验证](references/sync-and-validation.md)，生成真实音频轨并接入选定引擎。真实点击/打字配合适的物件拟音；合成系统提示音只用于明确的系统提示语境。剪辑到动作需要的窗口，控制重复、音量阶梯和密度，为音乐和必要配音留空间。
6. 从编码后的最终文件测量与回看。完整片默认提供配乐版及保留同一音效轨的无配乐版，用户另有交付范围时遵从。检查两版画面和 SFX 的时间线一致性。汇报所选曲目、实际处理、已测偏移及是否真正试听；没有听音能力时清楚标注听感未验证，不以音量值代替。

完成条件：本次要求的候选或音轨已实际产生，来源与处理可追溯，当前最终文件的同步/电平有相应检查，未将未做的试听或作曲描述为已完成。
