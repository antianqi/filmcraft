# 成片审查

## 输入与范围

读取当前简报、已批准分镜、最新 MP4、关键帧、功能到镜头映射、来源和声音表。若用了 Video Shotcraft，按 [依赖与引擎](../filmcraft-video/references/dependencies.md) 定位并读 `final-review.md`、`aesthetic-rules.md` 及选中卡片/demo。缺失输入明确标记，不根据制作者的预期补出结论。

独立审查应使用未参与制作、可读取实际成片的审查者；有子代理能力时委派干净上下文的终检。给简报和证据，不给预设结论。没有独立审查条件时做可执行自审并注明范围。只读审查不改源；用户要求修复时再将问题交回制作流程。

## 顺序

1. 确认实际最新文件和哈希。对最终编码文件抽帧，而非只看 Studio 或旧预览。
2. 按 [审查清单](references/review-checklist.md) 检查每个镜头的新信息、真实能力、唯一焦点、素材/原创表达、动作弧和阅读时间。重点查用户已指出的问题，不能只检查播放器参数。
3. 查看动作连续帧与切点前后帧。放大必须读的控件，缩小到约 480px 宽测试小窗阅读；对光效、边框、圆角遮罩、透视文字和相机跳位看全尺寸。
4. 检查声音事件与来源；只有实际试听才能判断听感。参数、完整解码和两版画面一致性可调用 `../filmcraft-video/scripts/inspect_delivery.py`。播放、同步、试听、动态参考一致性分别记录。
5. 用编号、严重度、是否阻止交付、秒数/帧号、截图和修复建议报告问题。检查发现的问题必须有具体证据，不能为了清单完整编造问题或全部打勾。
6. 复查修订后的新文件、受影响片段及相邻切点，再更新当前报告/哈希。确认没有剩余必须修复项后才能给出该范围的通过结论；建议项、缺失证据和创意验收状态单列。

完成条件：报告对应实际检查过的文件，问题可定位，结论没有超出图像、播放或音频证据。审查“通过”不自动代表用户创意认可。
