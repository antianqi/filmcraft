# 审查清单

结合 [画面与连续性](../../filmcraft-video/references/visual-direction.md) 和外部 Shotcraft 当前清单，不把这份列表当成所有影片必须使用相同风格的模板。

| 维度 | 检查 |
| --- | --- |
| 目标与证据 | 受众和收益是否清楚；输入、改动、结果是否同一任务；草稿/动画/实际执行是否分清；是否出现未证实的能力 |
| 设计 | 原创部分是否表达产品含义；真实素材是否被提炼；是否只剩录屏过场或抽象装饰；品牌视觉是否有来源 |
| 构图 | 每帧主次、遮挡和字幕层是否稳定；线条、手机边框、代码或多层面板有没有穿过主要文字 |
| 节奏 | 动作有加速和终点吗；长静止是否有阅读理由；开场是否完整；品牌是否有停留；是否用空白或轻微漂移凑时长 |
| 连续性 | 同一对象的末态/初态是否接续；相邻切点是否意外出现空帧、跳位或重影；横竖屏素材比例是否正确 |
| 可读性 | 必须阅读的按钮、Diff、结果、字幕和 CTA 在最终像素及小窗中是否可读；是不是用大字幕掩盖小操作 |
| 材质与渲染 | 原始素材和栅格化链路是否足够清晰；是否等待字体/图片；随机跳帧是否一致；后续镜头有无遗留图层 |
| 声音 | 音源/许可/处理可追溯吗；动作窗口与峰值是否对齐；输出偏移是否实测；有没有真正听过成片 |
| 交付 | 时长、比例、帧数、codec 正确吗；两版画面与音效是否按约定一致；报告是否对应最新母版 |

## 报告格式

```text
文件/版本/哈希：
实际检查：关键帧 / 连续帧 / 完整播放 / 实际试听 / 参考对照

V01 | P2 | 阻止交付 | 48.0s / f1440
问题：字幕与手机边框相交，关键字无法辨认。
证据：截图路径与检查方法。
建议：不透明浅底或调整到稳定区域；复查字幕入场、停留、退出。

已关闭项：对应新文件和复查帧。
剩余建议：不阻止本次交付的改进。
未验证：缺失资料、没有完成的试听或远程样片核验。
结论：仅限上述检查范围。
```

阻止交付的典型问题：虚构产品能力或泄露敏感数据；关键结果不可读；严重遮挡/比例错误；与批准分镜实质不符；明确的音画错位/损坏；用户明确禁止的结构仍主导成片。一般审美建议与可接受的刻意改编单列，不把每个偏离参考 demo 的地方都升级为故障。
