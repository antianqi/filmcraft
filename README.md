# 影片工坊 Filmcraft

把一个可讲清的任务，做成一支有设计、有产品证据的视频。

插件包含三个可以分别调用的技能：

| 技能 | 使用场景 |
| --- | --- |
| `filmcraft-video` | 从网页、产品、素材制作视频；先设计分镜；继续已批准方案；修改画面 |
| `filmcraft-audio` | 给已有视频选配乐、找音效、制作混音、修正同步 |
| `filmcraft-review` | 独立检查成片的叙事、构图、节奏、可读性与技术交付 |

示例：

- “用影片工坊为这个产品做一支一分钟宣传片，先设计，不制作。”
- “按刚才批准的分镜继续制作，用 MotionHarness，交付工程和 MP4。”
- “保留画面，为这支片子重新选配乐和拟音。”
- “自审这支视频，重点检查是否像 PPT、画面是否杂乱、按钮是否看得清。”

## 安装

```bash
git clone https://github.com/antianqi/filmcraft.git ~/.minimax/plugins/filmcraft
```

也可以直接把本目录复制到 MiniMax Code 的插件目录 `~/.minimax/plugins/filmcraft`。插件是技能型插件，不含 MCP 服务与云端渲染；它依赖本机已安装的 `motionharness` 与 `video-shotcraft` 技能，以及 `mh`、`ffmpeg`、`ffprobe` 和 Python 3。

## 分工和依赖

Video Shotcraft 提供镜头配方、调校示例、音频选材与审查方法；MotionHarness 提供本地动画实现、Studio、预览、渲染和版本保存。Filmcraft 管理它们之间的故事线、素材、设计决策和验收。

制作环境需要本机可执行的 `mh`、`ffmpeg`、`ffprobe`、Python 3，以及已安装的 `motionharness` 和 `video-shotcraft` 技能。通过当前宿主的技能目录定位依赖；包内的发现脚本也会列出候选和缺失项，不安装或执行下载的软件。插件不自带这些工具或第三方技能副本。

这是技能型私有插件，没有 MCP 服务、云端渲染或独立编辑器。保存插件到账户不等于在网页端获得本地渲染能力。MotionHarness Standard 提供源码和音轨编辑；需要可拖拽图层时选择 Pro，并实际验证。

## 交付和边界

每个项目按自身品牌和用途设计，不把插件图标的黑白橙配色套到全部影片上。完整宣传片通常交付主片、保留音效的无配乐版、工程、素材来源及审查记录。用户明确缩小范围时按其要求交付。

素材和项目写入当前任务专用目录。插件包不包含原始会话、用户录屏、既有成片、账户数据、音乐文件或运行时缓存。真实页面操作、第三方下载、模型生成与付费服务仍遵循当前任务授权。

背景音乐可以来自授权素材或用户明确选择的生成服务；交付时区分现成曲目、原创作曲和脚本混音。技术解码、帧数与音量检查不代表实际听音或创意验收。
